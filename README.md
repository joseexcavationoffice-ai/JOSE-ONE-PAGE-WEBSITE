# Jose Excavation LLC — website

One-page site for Jose Excavation LLC, excavation and foundation contractor in Milford, MA. Live at https://joseexcavation.com.

- `site/` — the static site (HTML, CSS, vanilla JS). Upload the contents of this folder to the web root.
- `ferramentas/set-domain.ps1` — swaps the domain in canonical, schema, sitemap, robots and the form redirect.

Forms post to Web3Forms (`id="form01"`) and redirect to `/thanks/`. Tracking: GTM-KHQV72M9.
